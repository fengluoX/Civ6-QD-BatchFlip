# QD 批量倒卖

挂在 **Quick Deals（快速交易）** 的扩展页签：批量套利**外交支持**与**战略资源**。

## 依赖

- [Quick Deals](https://steamcommunity.com/sharedfiles/filedetails/?id=2460661464)

## 使用

1. 启用本模组 + Quick Deals  
2. 打开快速交易 → **批量倒卖**  
3. 勾选「外交支持套利」/「战略资源套利」，可调 AI 留金 / 自己留金 / 成交上限  
4. 点 **开始倒卖**，或开启自动执行（每回合按勾选项跑一遍）

## 说明

- 外交支持：廉价窗买入，逐点卖出  
- 战略资源：AI 库存 ≥40 时买空 → 卖回 40（0 库存高价）→ 再买回，循环榨干现金  
- 不修改 AI 估价，只批量执行已允许交易  
- 日志：`%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VI\Logs\Lua.log`

# QD 批量倒卖

挂在 **Quick Deals（快速交易）** 的扩展页签：一键对所有 AI 循环倒卖**外交支持**。

## 依赖

- [Quick Deals](https://steamcommunity.com/sharedfiles/filedetails/?id=2460661464)
- 可选 Better Quick Deal（「1:1 刷价」页签会保留）

## 使用

1. 启用本模组 + Quick Deals  
2. 打开快速交易 → **批量倒卖**  
3. 可调：保留 AI 金币 / 自己金币 / 单次上限 / 仅预览  
4. 点 **一键倒卖外交支持**

## 说明

- 已移除战略资源倒卖（易卡、收益一般）  
- 不修改 AI 估价，只批量执行已允许交易
